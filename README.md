🌍 Web Scraping - Countries of the World
This project focuses on performing Exploratory Data Analysis (EDA) on country-level data collected through web scraping from the "Scrape This Site Countries Of the World" platform. It includes data cleaning, normalization, and various visualizations to analyze the relationship between population and area (both normalized).
📦 Features:
- ✅ Web scraping using BeautifulSoup
- ✅ Data cleaning and normalization
- ✅ Histograms, boxplots, and scatter plots
- ✅ Correlation matrix
📁 Files Included:
- `scraper.py` – Script to scrape country data from the web
- `cleaned_countries_data.csv` – Cleaned and normalized dataset
- `eda_report.ipynb` – Google Colab / Jupyter Notebook with EDA code
- `EDA_Report_Countries_Data.pdf` – Final summary report
